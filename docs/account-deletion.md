# 账号注销与清理

在个人资料底部展开“注销账号”，填写当前密码与 `注销我的账号`，再次确认后才提交。第三方账号须先设置密码。服务端根据登录凭证确定账号，不接受客户端指定删除其他用户。

同一数据库事务删除当前账号的资料、登录凭证、会话与消息引用快照、长期记忆及授权设置、活动记录、运行追踪、第三方绑定和验证凭证。任何步骤失败都会回滚；共享知识库与模型资源不删除。新增写入归属检查，防止注销前的迟到任务重新插入已删除账号的数据。

成功后停止本页面摄像头、录音与播报，清除页面资料并回到登录界面。其他连接的凭证失效后不能继续授权请求。网络超时不代表删除失败：应重新登录确认状态。

这是项目在线数据库的逻辑删除，不宣称磁盘安全擦除，也不会自动清理部署者的外部备份。自动验收仅使用临时测试数据库，不删除实际用户账号。
