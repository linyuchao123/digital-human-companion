# 微信、QQ 登录与验证邮箱

当前为可配置接入实现；未配置时明确提示待配置。自动测试使用模拟授权和模拟邮件，不能替代平台真实验收。

## 配置

将 `.env.example` 的 OAuth 与 SMTP 项填入本地 `.env`，重启服务。真实密钥不可提交 Git，浏览器不得持有应用 Secret。

- 微信：申请微信开放平台网站应用，配置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和平台批准的回调域名。
- QQ：申请 QQ 互联网站应用，配置 `QQ_APP_ID`、`QQ_APP_SECRET` 和平台批准的回调地址。
- `OAUTH_PUBLIC_BASE_URL` 为站点根地址，如 `https://你的域名`，不可包含路径。回调分别为 `/api/auth/wechat/callback`、`/api/auth/qq/callback`。公网强制 HTTPS；本地地址仅供模拟测试，不保证平台接受。
- 邮件：配置 SMTP 主机、用户名、授权密码、发件地址。默认 SSL/465，也支持 STARTTLS/587；配置独立至少 32 字符的 `EMAIL_VERIFICATION_SECRET`。不支持明文 SMTP。

平台资格、审核及回调限制以平台控制台为准。本次官方协议文档访问失败，协议兼容性还需用申请到的应用完成实际授权验收。

## 用户流程

登录页可跳转平台授权，无需在本站输入微信或 QQ 密码。已有账号应先登录，在个人资料页输入当前密码主动绑定；不会按昵称自动合并账号。

资料页输入邮箱和当前密码，发送验证码，收到后验证绑定。验证码十分钟有效、最多五次尝试、一次性使用；数据库仅保存验证码摘要。验证邮箱可作为密码登录的身份标识，尚不提供邮箱免密登录或忘记密码找回。

首次社交登录生成独立账号，没有预设本地密码。授权后十分钟内可设置本地密码或验证绑定邮箱；超时需重新授权。设置密码会注销现有会话。

## 安全与上线验收

授权 state 与 HttpOnly 浏览器 cookie 绑定；回调只产生一次性短期票据，长期会话令牌不出现在 URL 中。绑定身份冲突不会覆盖其他账号。

上线后需实际验证两平台登录、取消授权、重复回调、跨浏览器回调拒绝、已有账号绑定、邮件投递、验证码过期及身份冲突。请设置精确 `ALLOWED_ORIGINS`，保护数据库和 SMTP 密钥。限流当前为进程内实现，多实例部署前应迁移共享限流存储。
