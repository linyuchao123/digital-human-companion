# V3 知识依据与问法验收

新增 18 条本地验收问法：12 条心理知识正例、6 条天气/电脑/歌曲等负例。初测 BM25 正例命中率 91.7%，负例误命中 16.7%；发现正念被通用词淹没、电脑内存升级误入心理检索。

为明确知识术语匹配增加小幅排序加权（每个完整语料关键词加 8 分），不修改原知识正文；补齐设备升级的域外过滤，带明确心理感受的混合问题仍优先保留。修复后本组 Top-3 命中率 100%，MRR 0.958，负例误命中 0%。这是本地自编回归集，不是独立用户准确率，也不代表回答医学正确性。原评测集继续回归，失败不修改期望文档掩盖问题。

知识性句子要求就近标注实际来源编号，寒暄和倾听不强行引用。最终正文移除不存在的数值引用，不补造编号；流式阶段仍为未完成模型输出，最终替换后才完成编号清理。此校验只检查编号存在，不证明句子与资料语义相符。参考卡片仍明确显示“未逐句核验”。语音不朗读编号。

每条助手消息保存最多 3 条精简公开来源快照（文档 ID、来源、400 字以内摘录、安全 HTTPS 链接）；无全文、无分数、无视觉或长期记忆资料。历史恢复使用当轮快照，不重新检索，避免语料修改后冒充旧依据。旧消息保持无参考，不追溯补造；损坏快照忽略，不阻断对话。沿用会话所有权鉴权，切换会话丢弃迟到请求，不重播历史语音。

原组回归：基础 8 条及自然问法 16 条均达到 100% 命中；混合问法 24 条正例命中率 91.7%、MRR 0.833、负例误命中 0%。混合组仍有“晚上脑子像开会”的隐喻问法漏检，保留失败结果，不宣称所有问法均完成。
