# 主对话、模式与长回复语音部署前验收记录

## 已自动验证

- 唯一主对话迁移可重复执行；首次升级优先选择最近更新且已有消息的会话。
- 登录、刷新和重连通过幂等接口恢复主对话；创建普通会话会复用已有空白会话。
- 主对话不可删除，只能二次确认清空；普通会话删除、账号隔离、注销清理均有回归测试。
- 会话列表与消息使用稳定游标分页；`limit=1` 时主对话不占用普通会话页，不重复、不漏项。
- 手动标题不再被自动标题覆盖；自动标题清洗后为 8～16 个汉字。
- 日常/情感模式和情感风格按会话持久化，并发请求通过 `ContextVar` 隔离生成参数。
- 分句语音能够跨文本增量识别完整句，单段不超过 180 字；切会话、切模式、退出、断线和关闭语音均取消旧队列。
- 1440×900 与 1920×1080 下左右面板宽度、外边距对称，输入栏几何居中；1024 与 390×844 无横向溢出。
- 左右面板拖拽联动；Live2D 每次按首次加载的原始尺寸重算缩放，避免累计缩放。

本地完整结果：333 项 Python 测试通过，6 项因可选视觉/语音/模型依赖跳过；全部 Node 前端脚本通过。远端 `f2af008` 与 `4fe5abf` 的 GitHub Actions 已全部通过。

## 上线前仍需真人与设备验收

- 在实际部署密钥和网络下完成 24 组 DeepSeek/千问盲评。千问只有在平均分领先至少 0.5、无关键边界失败、首句延迟中位数增加不超过 1 秒时才能替换情感默认模型；当前仍为 DeepSeek 主、千问备用。
- 使用同一台目标设备、同一音色，对改版基线和当前版本各测至少 10 次首音延迟。仓库没有改版前的同机实测数据，不能补造“前测”结果。
- 使用真实扬声器确认长回复句间连续性、弱网缓冲、打断后不重播、嘴型在无音频时暂停，以及整轮动作只触发一次。
- 使用真实摄像头确认权限、开启/关闭、切会话和退出时释放设备；确认观察措辞保留不确定性。
- 使用真实 DeepSeek/千问、云 ASR、云 TTS、知识库和长期记忆完成一次端到端人工体验。
