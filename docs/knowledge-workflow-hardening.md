# 心理知识工作流验收

## 含蓄表达与路由

补充带个人语境的局外感、自责、亲人去世、睡前反复想事、工作优先级等本地信号，以及心理咨询科普入口。这是确定性路由补充，不是心理诊断或完整语义分类器，不增加云端分类请求。

含天气词的心理表达（例如“下雨天觉得孤单”）不自动查询天气；明确的预报、搜索或天气问题仍优先调用对应工具。用户只想倾诉时跳过知识库；危机分诊、遗忘请求保持原优先级。“推荐一首失眠的歌”不因歌名触发心理知识。

`tests/test_knowledge_route_coverage.py` 直接运行LangGraph，对扩展开发集12个正例检查知识节点、原查询、无分类器及无联网调用，另测娱乐、天气、倾诉、遗忘与安全边界。它与检索评测互补：路由正确不意味着检索或最终回答一定正确。原样例参与开发，不能当独立用户准确率。

```sh
.venv-model/bin/python -m unittest discover -s tests -p 'test_knowledge*.py'
```
