# 已验证邮箱找回密码

登录页“忘记密码？”可使用之前绑定并验证的邮箱。未绑定邮箱无法找回，不允许通过用户名或生日重置；可使用已绑定的第三方登录后设置密码。

复用 `.env` 的 SMTP_HOST、SMTP_PORT、SMTP_SECURITY、SMTP_USERNAME、SMTP_PASSWORD、SMTP_FROM 和独立 EMAIL_VERIFICATION_SECRET。SMTP_PASSWORD 应为邮件服务授权凭证。无配置时入口明确提示不可用，不会伪装发送成功。

`/api/auth/password/reset/send` 返回统一说明，不区分未知邮箱与已绑定邮箱。邮件后台发送；失败仅清理本次验证码，不输出邮件、验证码或异常正文。响应说明是请求受理，不是送达保证。六位验证码10分钟有效，单邮箱60秒发送一次，每IP15分钟最多5次发送，最多20次确认；单验证码错5次失效。多实例环境现有限流仍是进程内，需部署级共享限流补强。

验证码仅存带用途隔离的HMAC摘要与随机盐；绑定验证码不能用于重置。确认以数据库事务锁保护一次性消费，成功后更新bcrypt密码、撤销所有登录Token、待完成OAuth授权和邮箱验证码。已有WebSocket沿用每条消息的登录有效性检查。主动改密也清除旧重置验证码；邮箱变更后旧地址不能重置。

测试覆盖未知邮箱统一响应、一次性消费、旧密码与Token失效、新密码登录、过期、错误次数上限、发送限流、主动改密后失效、邮件配置缺失及发送失败清理。浏览器不存验证码或新密码，成功清空敏感输入。

真实SMTP投递与浏览器邮件往返尚未验收，不以Mock邮件测试代替送达。账号彻底注销和持久化语义摘要为下一小项，尚未实现。
