# 持久化会话摘录

会话较长时，将超出最近38条消息的用户原话按偏好、目标、称呼与资料、日常背景分类摘录，最多8条、每条原话160字。只有已登录并开启长期记忆授权时才保存；授权开启之前的历史不追溯提取。关闭授权或清除记忆会清空摘录并推进处理水位，防止重新从旧历史提取。删除单条记忆或对话内要求遗忘也保守清空该账号的所有会话摘录，不删除聊天历史。

摘录按用户和会话隔离，重连后仅用于原会话，不跨会话自动拼接。不保存助手推测、密码等敏感字段、提示词注入或安全分诊判定不宜记忆的内容。当前用户更正优先，模型只能将摘录作为不可信的前文参考。它是确定性的分类摘录，不是大模型生成的全面语义总结，也不保证识别全部敏感信息。

每轮结束在回复已发送后增量处理，最多扫描200条历史；不增加额外大模型调用。授权修订号防止关闭授权、清除记忆之前的迟到任务写回。摘要更新失败不影响已经发出的回复。账号注销与会话删除同步删除对应摘录。测试使用临时数据库覆盖持久化恢复、有界处理、隔离、撤销与旧任务保护。
