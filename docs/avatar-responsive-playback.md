# 数字人语音与动作验收

## 语音

千问音色优先走 `/api/tts/stream`，接收 24 kHz 单声道 16 bit PCM 后直接排队播放，不再等整段 WAV 下载及解码。关闭语音、新输入、断开连接会取消请求并停止已排队音频。首包失败仍可回退原合成接口；已经播出的流中断不会从头重复播报。

本地短句实测：直接厂商首包 0.69 秒；经本地接口首包 1.12 秒。该数值不是浏览器扬声器开始出声的延迟，网络及文本长度会影响结果。

验收：刷新 http://127.0.0.1:8801，选择云端 Cherry，用打字、语音分别提问，听文字出现后语音是否及时跟上；播报中再次输入、静音，确认旧语音不再继续。

## 原模型及新增动作

资源路径为 `digital_human_engine/live2d_web/shizuku/`。原生 FlickUp、Tap、Flick3、Idle 四组动作完整存在，时长约 1.27、1.27、1.50、1.57 秒。原来每帧锁定部件、归零手臂并覆盖外部参数，会遮蔽原生动作；现在原生动作期间暂停这些覆盖，但保留音频口型。

新增问候、点头、摇头、思考、庆祝、安慰、倾听为已有参数骨骼上的轻量程序动作，使用平滑包络、互斥和冷却限制。不是重新绘制的手势或新增骨骼。问候、成功庆祝等输入会选择相应动作，其他情况依据情绪及安全状态选择。工具栏“动作预览”可单独检查全部动作；动作播放期间或冷却期间的新请求会忽略，避免突然切换。

复杂挥手、全身动作需要可编辑 Live2D 工程、补绘及绑定；仅有编译后的 moc3 无法生成原本不存在的绘图部件。原始模型文件未修改，素材的开源来源及再分发许可仍需确认。

## 背景颜色

背景由对话情绪指令更新：Happy 为绿色，Sad 为蓝灰色，Anxiety/Fear/Concerned 为紫色，其余恢复默认浅蓝色。并非随机变色或按时间变色。更新时仅替换情绪主题类，不清空页面其他样式类。

个性化活动推荐暂不继续扩展，已有活动记录功能保留。

### 动作幅度与节奏调整

轻量动作增加头部和上身幅度，点头上限约 14、摇头约 17 个参数单位（不是实际屏幕角度）。每个动作分为柔和进入、短暂保持和较慢退出；点头第二次幅度降低，摇头只左右一次，庆祝仅头部和身体轻摆，避免所有参数同步抖动。取消轻量手臂偏移，保留原生动作中的手臂表现。结束时回到当前驱动姿态，避免恢复过期参数造成跳变。

运行 `node tests/avatar_gestures.cjs` 可检查动作幅度边界、重复帧不积累偏移及结束回正。自然度仍以真人界面试听和动作预览验收为准。

后续微调：问候改为使用原生动作已有的另一套左臂部件，抬臂并轻摆手掌、结束收回；参数限定在 -1～1。点头改为一次低头抬回（头部 -12、身体 -0.5），不再重复起伏；摇头仅控制头部左右，幅度增至 26 个参数单位。以上替代前文对应旧版参数；手臂朝向与视觉效果需在模型预览中确认。

最新调整替代上述问候：取消自行拼接的抬臂参数和部件交叉渐变，Hello 复用作者的原生 Idle（04）手臂动作，保留其原有曲线，不宣称是新制作的标准挥手。

入场不再使用 FlickUp 配合猜测时长。主界面显现时启动 2.55 秒独立唤醒时间线：闭眼停留 0.35 秒、约 1.1 秒柔和睁眼、轻抬头、一次困倦小眨眼，最后 0.55 秒交还正常驱动。入场覆盖在外部驱动之后应用，并阻止其他动作抢占；断开时取消。刷新后断开再连接可验收完整入场过程。
