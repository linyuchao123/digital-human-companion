## 自动化门禁说明

- 当前生产链路的账号、会话、记忆、活动、智能体、RAG、云 ASR、TTS、摄像头、运营后台和前端交互测试应全部通过后再部署。
- `tests/test_asr_module.py` 是遗留的本地 FunASR 模型下载测试，不代表生产所用的千问云 ASR。
- `tests/test_vision_module.py` 含遗留 Windows 本地路径，生产页面使用 `/api/vision/face-landmarker-model` 提供的浏览器模型。
- `tests/test_multimodal_fusion.py` 使用了旧协议类型名，属于待迁移的实验性离线融合测试；生产摄像头链路由浏览器本地观察与智能体上下文接口覆盖。
