## 2D 长语音编排

在真实语音启动后，保留首个语义动作。长回复第八秒起，最多补充三次已有的倾听、安慰或思考轻量动作，每次至少间隔十秒。短回复不会额外动作，不重复问候、摇头或夸张庆祝。

编排复用渲染循环，无额外轮询定时器；服务端语音以音频时钟计时，暂停、缓冲静音、后台页面或已有动作播放时不触发。结束、取消、断线和新播报清除计划，已有轻量动作自然回正。编排不控制嘴型、眨眼或手臂，不改变音色与 TTS 请求。

人工验收：试听 5 秒、20 秒、40 秒以上回复，检查动作不突兀、无重复问候；播报中录音打断和断线，不应继续启动旧动作。此体验尚未代替用户完成。

## 模型增量文本

DeepSeek/千问兼容接口请求 `stream=true`，仅消费 `delta.content`，不显示推理字段；参考 DeepSeek 官方文档 https://api-docs.deepseek.com/api/create-chat-completion/ 。首段失败可尝试备选模型，已输出内容后断流则报错，不拼接其他模型的回答。

WebSocket 以 trace_id 绑定 `llm_thinking`、`llm_delta` 和最终 `llm_reply`。增量只更新气泡，最终回复替换正文并添加来源和情绪信息；TTS 仍只在最终回复启动一次，不因每个 Token 重复请求语音。首句语音与生成并行留到 TTS 条目另行完善，本项不能宣称已达到文字和音频同时到达。

摄像头、记忆和知识安全上下文沿用原回复节点，增量回调不写图状态或数据库，ContextVar 按并发任务隔离。工具确定性回复、高风险安全回复和离线回复不模拟逐 Token 输出。重连、断开和切换会话丢弃旧增量。

一次本地真实模型 WebSocket 冒烟验收：29 个增量事件，首增量 5.083 秒、最终正文 5.382 秒，拼接结果与最终正文一致，无断流错误。这是单次结果，不是延迟 SLA，也不代表浏览器试听已验收。
