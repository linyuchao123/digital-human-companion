# 智能体联网搜索

在根目录 `.env` 配置 `TAVILY_API_KEY=你的密钥` 并重启后端。到 Tavily 控制台申请密钥；不把真实值提交 Git 或发到前端。Docker Compose 已传入此变量。

## 验收问法

- “你知道现在几点吗”：读取真实时钟，默认北京时间，不调用搜索或大模型。
- “今天天气怎么样”：先问城市；回答“上海”后查询当前日期天气资料。
- “上海今天天气怎么样”：直接查询资料，再由对话模型回答并展示来源。
- “联网搜索最新消息”：调用 Tavily，并显示最多三条链接。
- 普通情绪聊天：不主动联网。高风险安全响应始终优先。

当前城市识别为常用中文城市名单，未覆盖城市会要求补充；不自动定位、不跨会话保存位置。通用搜索目前主要依靠明确搜索问法触发，尚不是自由多步工具规划。天气现改用下面的专用数据接口。

## 专用天气工具更新

天气已改用 Open-Meteo 地理编码与天气模型 API，不再使用 Tavily 的旧网页回答天气。只发送城市名、坐标和天气变量，不发送用户对话给天气厂商。

支持当前模型天气和今天、明天的日预报；超过三小时或超前十五分钟的数据拒绝用于回答。字段缺失、温度或概率异常、超时均明确提示失败，不回退旧网页，也不让大模型猜测数值。回答注明北京时间、预报日期、Open-Meteo 来源及非气象站实测。

免费公共接口无需新增密钥，但仅限非商业用途，遵守供应商调用限制及署名要求。商业或广告/订阅场景须使用适用付费服务；生产多用户场景还需共享缓存及全局限流。

官方文档：https://open-meteo.com/en/docs
地理编码数据来源：GeoNames https://www.geonames.org/
使用条款：https://open-meteo.com/en/terms

固定使用 `https://api.tavily.com/search`，basic 深度、最多三条结果、十秒超时，不自动重试放大费用。只发送当前查询（天气包含城市、日期），不发送会话历史；用户主动搜索的文字可能包含隐私，请避免输入敏感信息。网页摘要是不可信资料，提示模型不得执行其中指令；不能保证仅靠提示完全防住提示注入。结果链接过滤危险协议及明显内网地址，不由后端抓取页面。

未配置、超时、额度或鉴权失败时明确提示，不能声称已联网。自动测试使用模拟结果；真实 Tavily 搜索需填写密钥后验收。当前来源只在当次回复展示，历史会话来源持久化尚待完善。

官方接口文档：https://docs.tavily.com/documentation/api-reference/endpoint/search
# 连续天气追问

## 工具失败与超时

天气调用整体最多等待 13 秒，搜索调用最多 11 秒，搜索后的回答生成最多 20 秒（不包含前置工作流开销）。超时终止当前调用，不自动重试以免重复消耗额度；可重新发送问题。搜索成功、回答失败时保留来源，搜索失败时不声称已取得资料。开发者事件及执行记录包含工具名、失败状态及脱敏错误类型，不发送异常原文或密钥。取消对话仍沿用现有任务取消链路，不转换为工具失败。

支持“上海天气 → 那明天呢 → 适合出去散步吗”，继承上一条天气回答的城市及预报日期；明确指定新城市或日期时优先使用新输入。只承接紧邻的、带日期的 Open-Meteo 天气回答，不从其他用户或全局状态读取地点，也不承接过期日期或被普通聊天打断的查询。

散步建议基于温度、降水概率及天气代码保守判断，不代表出行安全保证；回答提醒检查实际天气、空气质量和当地预警。当前仍仅支持今天、明天，城市范围沿用现有配置。
