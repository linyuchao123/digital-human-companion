# 流式语音连续性验收

保持当前音色和正常网络缓冲参数不变。网络读完不代表播报结束：仅在 EOF 且本轮全部音频源实际结束后清理嘴型和说话状态，暂停音频时不会由墙上时钟提前恢复录音。旧轮结束不能清理新轮。

请求或分片连续 15 秒无响应会取消，不延长等待重复请求。已开口后断流不重复从头播报、不自动换音色；其他未开口的流式接口失败仍可尝试原音色完整音频路径。PCM 最后一个不完整采样视为断流。

浏览器控制台 `window.__ttsStreamMetrics` 保存最近 100 次流式请求的本机数值。开发者面板可点击“语音指标”查看最近20次的完成率、首字节、文字到首音排程、提交到首音排程中位数与P95、缓冲耗尽次数，也可导出本地JSON。没有正文、音频、账号或设备标识，不上传。提交到首音从文字或录音提交时开始；不包含用户录音时长。首音排程仍不是实测扬声器真正出声时间。

正常网络继续使用320ms首段缓冲。最近5次流式播报中至少2次发生缓冲耗尽时，下一次首段缓冲自动提高到560ms，降低相同抖动重复造成断续的概率；网络恢复后最近窗口自然回到320ms。它不会掩盖耗尽指标，也不能保证超过已缓冲音频长度的长时间断网仍连续。

人工验收：保持同一音色分别试听短回复和40秒以上回复；在浏览器开发者工具选择 Fast 3G 等限速后至少播放5次，再恢复正常网络重复；测试断流、暂停AudioContext、取消后立即重新播报。导出两组指标比较中位数、P95、完成率和耗尽次数，并人工记录真正听到首音的时间。自动测试只验证调度和计算，不代替弱网试听。
