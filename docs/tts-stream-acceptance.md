# 流式语音连续性验收

保持当前音色和正常网络缓冲参数不变。网络读完不代表播报结束：仅在 EOF 且本轮全部音频源实际结束后清理嘴型和说话状态，暂停音频时不会由墙上时钟提前恢复录音。旧轮结束不能清理新轮。

请求或分片连续 15 秒无响应会取消，不延长等待重复请求。已开口后断流不重复从头播报、不自动换音色；其他未开口的流式接口失败仍可尝试原音色完整音频路径。PCM 最后一个不完整采样视为断流。

浏览器控制台 `window.__ttsStreamMetrics` 保存最近 100 次流式请求的本机数值：首字节、首音排程耗时、音频设备估计延迟、缓冲耗尽次数与完成状态。没有正文、音频或身份数据，不上传。首音排程不是实测扬声器出声时间，也不是输入到首音的端到端延迟；浏览器完整体验验收仍未完成。

人工验收：保持同一音色分别试听短回复和 40 秒以上回复；模拟网络抖动、断流与暂停 AudioContext；取消后立即重新播报；连续模式应在实际结束后恢复录音。记录输入、首文字、最终文字和实测首音的时间，比较中位数及长语音间隙，不以单元测试代替弱网试听。
