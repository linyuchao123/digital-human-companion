# 自动检查与验收边界

每次推送运行两种 Python 3.12 环境：

- `core`：仅安装项目核心依赖，检查缺少本地模型依赖时的协议、接口、安全和降级行为。
- `cpu-model`：另外安装固定版本 CPU PyTorch 2.8.0，运行完整单元测试，覆盖数字人模型与评测工具逻辑。不会下载大模型或上传本地模型权重。

需要 PyTorch 的评测工具测试在核心环境明确跳过，在 CPU 模型环境运行。训练权重、真实录音、GPU 或摄像头实测仍需单独验收，不能以 CI 通过代替。

前端检查包含动作、语音同步、摄像头质量及生命周期、文字发送可靠性和知识引用交互测试；Compose 检查只验证配置，不代表容器已经启动验收。

`scripts/manual_llm_smoke.py` 是历史本地 Qwen/RAG 手动验收脚本，需要自行准备模型和可选依赖，不属于自动单元测试。可运行 `python scripts/manual_llm_smoke.py --help` 查看模式。

推送后必须检查对应提交的 GitHub Actions 最终结果。旧提交的失败标记不会因新提交通过而消失。
