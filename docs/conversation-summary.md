# 当前会话上下文摘录

最近38条历史消息继续作为完整上下文；被截断的用户原话最多保留8条，每条160字。下一轮继续累积，容量满后淘汰最早摘录。助手回复不提炼为用户事实，不新增模型请求。

摘录以转义的不可信数据提供给陪伴回复节点，当前用户更正优先。不进入长期记忆、工具分类或搜索查询。会话切换清空，删除记忆指令清空当前摘录。只存在连接的会话状态里，重连不恢复，也不支持跨会话记忆；原聊天记录和授权长期记忆仍按原有功能管理。

这是低延迟、有限容量的原话摘录，不是语义摘要，无法保证无限长对话或所有细节保留。后续可评估异步语义压缩和持久化，但需要单独设计授权、删除及过期策略。

测试：`.venv-model/bin/python -m unittest discover -s tests -p 'test_conversation_summary.py' -q`。
