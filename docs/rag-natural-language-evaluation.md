# 日常问法检索验收

评测集 `eval/rag/natural_language_cases.json` 包含12条心理教育问题和4条无关问题。期望知识ID人工指定，部分问题允许多个合理来源；负例用 `expect_no_results: true`，必须没有期望ID。

命中率与MRR仅以正例为分母；负例单独计算误命中率，任何返回的知识片段都算误命中。默认 `--max-false-positive-rate 0`，出现误命中时命令退出码为1，即使正例全命中也不通过。可查看 `failures` 中的返回ID定位问题，不应为了通过而随意放宽阈值。

离线命令：

```sh
.venv-model/bin/python scripts/evaluate_agent_rag.py --cases eval/rag/natural_language_cases.json
.venv-model/bin/python scripts/evaluate_agent_rag.py --cases eval/rag/natural_language_cases.json --embedding-model models/embedding/bge-small-zh-v1.5 --require-provider hybrid_with_fallback
```

这测的是直接调用检索器，不是主界面所有聊天都会触发知识检索；主界面仍有意图路由。混合检索可以为没有词面匹配的无关问题返回候选，不能把相对排名当可信度。下一步需扩大负例和保留独立测试集，校准相关性过滤/重排，避免用极少样本拍脑袋定阈值。

小规模人工样例只用于回归与发现问题，不是心理学效果、真实用户准确率或临床验证。本次不改线上检索阈值，不新增API调用，也不影响语音链路。

## 领域过滤改进

工厂创建的检索器在主检索与降级之前先检查明确的领域外请求，包括天气、时间、歌曲推荐、餐饮选择、硬件连接、汇率与航班等。匹配心理表达或情绪困扰的混合请求不拒绝；未知表达仍放行，避免将规则词表当作完整心理领域分类器。原始BM25/Hybrid类保留原排序，不修改相似度阈值。

该策略部署到API与智能体共用的工厂链路，不允许空结果被内置降级再次填充无关知识。空结果只表示没有心理知识依据，不表示用户的问题无法通过其他工具回答。

同一16条开发集上，过滤后BM25与本地混合检索均为正例12/12、MRR1.0、负例0/4，通过既定门槛。此数据是开发集回归，不是独立测试准确率。专项测试另检查情绪混合请求，并确认原11条语义挑战问法在BM25模式的候选列表不因过滤改变。

局限：过滤是保守词面规则，仍可能遗漏无关问法或误判复杂表达，不能宣称所有无关结果已消除。下一步应收集独立用户问法，再评估语义相关性过滤或重排。

## 扩展口语与混合场景回归

新增 `eval/rag/mixed_query_cases.json`：12条心理相关正例、12条领域外负例，问法与原16条不重复，覆盖天气与孤单、音乐与睡眠、航班与睡眠，以及硬件、餐饮、行情等。期望ID人工指定，测试检查ID存在、正负例数量与问法唯一性。它是人工构造的扩展开发集，不是独立真实用户录音测试集；其中样例已用于修改规则，不能再当独立测试数据。

```sh
.venv-model/bin/python scripts/evaluate_agent_rag.py --cases eval/rag/mixed_query_cases.json
.venv-model/bin/python scripts/evaluate_agent_rag.py --cases eval/rag/mixed_query_cases.json --embedding-model models/embedding/bge-small-zh-v1.5 --require-provider hybrid_with_fallback
```

2026-09-13，Top3，修复前BM25正例10/12、MRR0.7917；混合检索正例11/12、MRR0.9167；负例均0/12。发现“下雨天觉得孤单”被天气规则误过滤，补充孤单、没人陪和睡眠表达的保护信号，避免领域外词覆盖同句的心理困扰。不改变排序、相似度阈值或TTS/动作链路。

修复后BM25正例11/12、MRR0.875、负例0/12；混合检索正例12/12、MRR1.0、负例0/12。原16条BM25仍为12/12、MRR1.0、负例0/4。现有验收门槛均通过，但纯BM25仍漏检“晚上脑子像开会，躺床上想工作”这一睡眠担忧表达，保留失败记录，不增加无关期望ID来凑命中。命中表示Top3含至少一条期望知识，不意味着所有候选相关，也不评价最终回答质量。

下一步优先补充检索触发的路由评测（本文件只测检索器），再用未参与调参的真实用户问法验证含蓄表达与候选相关性。没有真实录音时不能声称ASR或端到端准确率提高。
