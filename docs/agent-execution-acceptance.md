# V3 受限执行与恢复

仅改进现有时间、天气和联网检索能力，不增加工具或开放模型执行命令。模型路由仍只接受固定工具名，不接收执行参数；安全分流和禁止联网优先。

现有搜索按“取得资料→依据资料回答”依赖执行。检索失败不进入回答生成；回答失败保留已取得的来源并明确说明失败，不改为无依据实时回答。联网检索总预算 11 秒、天气总预算 13 秒，回答生成另有 20 秒上限；无循环扩展计划。

只读网络步骤遇到传输异常最多重试一次，退避 100 毫秒，所有尝试共用原总预算。配置缺失、HTTP 状态错误、无资料、无效数据不重试；记忆写入和删除不自动重试，取消继续向外传播。错误追踪只保留固定错误码，不记录异常正文中的密钥或地址。

明确以逗号等分隔的“现在几点，上海天气怎么样”组合请求会同时回答本地时间和天气；缺城市先澄清。天气失败仍可回答时间，并明确天气无法确认。不从天气语句里的“明天”推断时间子请求。此为确定性受限组合，不是任意任务自主规划。

自动测试覆盖预算、重试上限、不重试错误、取消、安全优先、禁止联网、组合成功与部分失败。真实厂商网络抖动恢复仍需实测。
