数字心屿使用指南

从第一次连接，到一段真正连续的陪伴。

欢迎来到数字心屿。
这是一个由 AI、语音与数字人表情驱动的日常情绪陪伴空间。你可以打字，也可以用麦克风说话；小安会结合当前对话模式回应，并用语音与动作陪你继续聊下去。它适合日常交流和情绪梳理，但不能替代医疗诊断或专业心理治疗。

💬 如何开始对话

  1. 完成注册后，本指南只会自动出现一次；以后可随时从顶部“使用指南与反馈”重新打开。
  2. 点击“连接数字人”进入陪伴空间。电脑端可输入文字或点击麦克风；手机端点击麦克风切换语音模式，按住说话、松开即发送。
  3. 通过左侧历史按钮切换旧对话；点击“＋”建立一段新的对话。
  4. 需要重新听一遍时，可使用“朗读”或设置菜单中的朗读工具。

🌿 两种对话模式

  • 日常对话：适合问候、陪聊、学习生活分享与轻松交流。
  • 情感对话：适合倾诉、情绪梳理和被认真倾听；还可选择“知心”或“温柔亲昵”的回应风格。

请放心表达真实感受。若你正处于紧急危险或严重心理危机，请优先联系身边可信任的人和当地专业援助服务。

✨ 你可以使用的功能

  • 切换数字人形象与播报音色
  • 管理长期记忆，并随时关闭授权
  • 查看活动记录与历史会话
  • 使用心理学知识库辅助回答
  • 开启本机摄像头感知与语音朗读

🔐 隐私与使用提示

  • 摄像头画面仅在当前设备本地处理。
  • 表情识别只是辅助观察，不等于真实情绪判断。
  • 运营统计不会向管理员展示密码、验证码或 API Key。
  • 长期记忆默认关闭，是否开启由你决定。
